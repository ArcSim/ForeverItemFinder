Just play

With the addon installed, the new items you loot reach every player using it on your ruleset, and theirs reach you. Nothing to set up. In Settings you choose to be credited by name or stay anonymous.

Found something it missed?

An item sold by a vendor, a quest reward, a rare drop, or a drop place that looks wrong: tell us so it can be added for everyone.

No GitHub account?

Post it in the Discord instead. The item's name, where you got it and your level are all we need.

What you get

  • Live Feed: new and changed items as players find them, newest first, with where each one dropped.
  • Item Database: every new Forever item, searchable by name or zone, filtered by level, quality, slot, class, source, and dungeon or raid.
  • Where it drops: a map with every known spot, the boss, mob, vendor or quest, and the drop rate where it is known.
  • Pop-ups: a card the moment a new item is found, filtered the way you choose.
  • Full tooltips: pin an item's tooltip beside the window, or link it in chat.
  • World Map pins: send an item's drop spots to your World Map with a waypoint.

Type /fif in game or use the minimap button to open it.
